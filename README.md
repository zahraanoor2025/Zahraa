# Kalam Inspired Presentations Demo

هذا المشروع عبارة عن تطبيق واجهة أمامية بسيط يعرض مثالين لبرزنتيشن (عرضين تقديميين)
مستوحاة من الهوية البصرية لموقع [kalam.cx](https://www.kalam.cx/). تم التركيز على استخدام
لوحة ألوان متقاربة مع العلامة التجارية وإظهار شعار مخصص بنفس الروح.

> **ملاحظة:** بسبب قيود الاتصال بالشبكة داخل بيئة التطوير، تم اعتماد درجات ألوان تقريبية
> بناءً على المعرفة المتاحة. يُرجى مراجعة فريق التصميم للتأكد من مطابقة القيم للألوان الرسمية.

## تشغيل المشروع

التطبيق عبارة عن صفحات HTML و CSS و JavaScript بسيطة. يمكنك فتح الملف
`public/index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط:

```bash
npx serve public
# أو باستخدام Python
python3 -m http.server --directory public 4173
```

بعد تشغيل الخادم، افتح المتصفح على `http://localhost:4173` لمعاينة الواجهة.

## البنية

```
├── public
│   ├── assets
│   │   └── logo.svg      # شعار مستوحى من Kalam
│   └── index.html        # نقطة الدخول الرئيسية
├── src
│   ├── scripts
│   │   └── app.js        # منطق الواجهة (التبديل بين الثيمات والتنقل السلس)
│   └── styles
│       ├── main.css      # الأنماط الأساسية للتطبيق
│       └── tokens.css    # المتغيرات (الألوان، الظلال، الحواف)
└── README.md
```

## الميزات الرئيسية

- قسم رئيسي تفاعلي يوضح هدف التطبيق وإجراءات سريعة للتنقل بين العرضين.
- تصميم عرضين تقديميين (Product Launch & Annual Report) بأسلوب متناسق مع الهوية.
- كتل إحصائية وتصميم بطاقات يتوافق مع الاتجاه من اليمين إلى اليسار.
- إمكانية التبديل بين الوضع النهاري والليلي مع حفظ التفضيل في التخزين المحلي.
- قسم إرشادي يوضّح لوحة الألوان وكيفية تعديلها عند الحاجة.
